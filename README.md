# Leasing y renting en proyectos

Exposición de Gestión de Proyectos (UPB, 2026-2): 26 diapositivas en HTML y el video animado
de la entrevista al profesor César Augusto López Gallego, que va dentro de la diapositiva 15.

- `diapositivas/`: la presentación. Instrucciones y teclas en `diapositivas/LEEME.md`.
- `video-entrevista/`: el video animado de la entrevista. Ver `video-entrevista/LEEME.md`.

## Verla en línea

El sitio se despliega en Vercel como sitio estático, sin build. La raíz redirige a
`/diapositivas/` (ver `vercel.json`).

## Verla en local

```bash
cd diapositivas
python serve.py
```

Abrir `http://127.0.0.1:8140/diapositivas/` y presionar **F** para pantalla completa.
